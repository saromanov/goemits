# Security Policy

## Supported versions

Only the latest released version of goemits is supported with security updates.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report them privately via [GitHub security advisories](https://github.com/saromanov/goemits/security/advisories/new). Include a description of the issue, steps to reproduce it, affected versions and, if known, a suggested fix.

You will receive a response within 7 days.
